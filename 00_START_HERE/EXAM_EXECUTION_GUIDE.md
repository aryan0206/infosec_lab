# Two-hour execution guide

1. Underline every algorithm, exact mode/key size, file name, input field, menu role, output, validation and “only after” condition in the question. Use [the checklist](QUESTION_REQUIREMENT_CHECKLIST.md).
2. On Windows, open `START_TOOLKIT.bat` from the project folder. It chooses a working Python 3.10+ interpreter (`IS_LAB_PYTHON`, `py -3`, `python`, then `python3`), runs `check_setup.py`, and opens the terminal router. Alternatively run `python -B check_setup.py` and `python -B exam_router.py` with your working Python executable. The RSA product needs only the standard library; the other listed submissions need `cryptography>=41` installed before the exam. Run `python -B check_setup.py --require-cryptography` to require that package immediately.
3. In the router, describe the required operations or browse the six one-file submissions. Select a preview number and read its **FULL/PARTIAL/UNSUPPORTED** items, exact file/command, inputs, dependency and limitations. Launch only after the separate confirmation. A phrase match is a starting point; compare **every** line of the question with the checklist.
4. Submit only the selected tested self-contained `.py` file: four known-pattern exports in `standalone_submissions/generated/`, or the generic `standalone_submissions/paillier_sum.py` or `elgamal_product.py` for their stated homomorphic exercises. The programs in `10_integrated_scenarios/` are development sources that still import `core.py` and `store.py`. The router checks generated files for staleness before launch; `python -B tools/build_submissions.py --check` does the same directly.
5. Replace demo data, period, fields, and examiner-supplied parameters. Do not edit crypto equations to make a sample pass.
6. Run each menu choice with valid input, invalid input and a tampered stored record. Show the encrypted values, verification result and final decrypted aggregate as requested.
7. Keep screenshots/output focused. State where modulus wraparound, MD5, toy ElGamal, timestamps, index or threshold simulations limit your claim.

For the known patient question, choose **L** in its menu to import the supplied JSON/CSV dataset into an empty patient directory. The required numbered choices remain 1–8 and **9 Exit**. For Lab 5 socket integrity, run `python -B 05_hashing_integrity_networking/socket_hash_demo.py server` in one terminal, then `python -B 05_hashing_integrity_networking/socket_hash_demo.py client --tamper` in another; the client compares the original message hash with the server's hash of the altered bytes.

Practice data from a generated submission is under `standalone_submissions/generated/demo_data/<scenario>/` when run in place, or under `demo_data/<scenario>/` beside a copied script. Keep its records and keys together for restart. Reset only the practice copy you intend to discard; a new key cannot decrypt old ciphertext.
